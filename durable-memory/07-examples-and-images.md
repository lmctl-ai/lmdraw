# Examples and README pictures

25 examples live in examples/. Twelve are stories with a known answer that the script prints and, where cheap, asserts: hydrogen-spectrum, kepler-second-law (PNG + 60-frame GIF), hohmann-transfer, carnot-cycle, lens-ray-diagram, incline-free-body, truss-bridge (Gaussian elimination, several DSL blocks sharing one scene), rc-lowpass, lotka-volterra (RK4), punnett-square (chi-square), mortgage-amortization, npv-irr-cashflow. Thirteen are API tours (title-card, node-tour, render-assets, animated-ladder, tween-morph, flow-pipeline, decision-flowchart, tree-org, table-metrics, chart-bars-lines, heatmap-grid, geometry-ellipse, arrow-helper).

Every example has the self-running shape: `out = ARGV...; mkdir images/build; p = _dsl_ cli="lmdraw" install="github:lmctl-ai/lmdraw@latest"; ... end _dsl_ savedsl(p, out); r = system ${dsl_cli(p)} --dsl ${out}; assert(r.code == 0);` then copy_file from build/rendered/ to images/NAME.png. Nothing reads repo files when run elsewhere: render-assets and animated-ladder fetch missing assets/*.svg with http_get from raw GitHub URLs; node-tour fetches the TTF with curl. GIFs are made with ffmpeg only when which("ffmpeg") finds it.

README pictures are docs/images/*.png and kepler-second-law.gif, copied from images/ by examples/render-all.sh (it runs every example with the local build first on PATH). The README gallery is grouped by theme; each caption is one line plus `lmctl autorun https://raw.githubusercontent.com/lmctl-ai/lmdraw/main/examples/NAME.lms`. docs/readme/render.sh only regenerates the architecture diagrams. The palette is dark (#0f1720 background, #e6edf3 text, #9fb3c8 muted, accents #f5c16c, #6fbdb4, #f08a6c, #7fa8d0, #b49cf0, #8fd694); panels are #16222e with #2c4156 borders, what-if panels #1b1a26 with #4b3f6b. Check every picture by eye after a change: overlapping labels and missing glyphs were the common defects.
